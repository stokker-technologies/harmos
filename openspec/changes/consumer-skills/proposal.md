# Consumer Skills

## Why

The current skills mix consumer architecture with Harmos repository maintenance and require unavailable company skills. Consumers need clear operation ownership, reusable runtime composition and a compact self-contained layout.

## What Changes

Refactor the existing architecture, authoring and testing skills with focused references. Record the user-agreed crate layout, domain/runtime split, vertical self-contained operations, facade features, resource boundaries and composed plugins. Move repository-only testing guidance into CONTRIBUTING.md. Preserve public APIs and describe current catalog and lifecycle mechanics accurately.

## Capabilities

### New Capabilities

- `consumer-guidance`: self-contained guidance for Harmos consumers, including shipped examples.

### Modified Capabilities

None.

## Impact

Consumer skills, their generated copies, README/CONTRIBUTING discovery and this specification, plus the user-authorized adoption of current Hub-generated conventions in root and embedded starter tooling/workflows. No runtime API, example source, Hub source or Dokime changes. Deliver one protected review into dev with auto-merge after source closure and targeted proof.
